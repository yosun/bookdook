# Safety Notes

- Offline only: This MVP does not perform network I/O beyond talking to a local model runtime (Ollama or llama.cpp) running on the same machine.
- Not legal/medical advice: Outputs may be inaccurate or incomplete. Always verify critical information.
- Hallucinations: Language models can fabricate details. Treat generated content as drafts.
- Privacy: Do not input sensitive personal data. All processing stays local, but protect your device.
